# 📊 Dashboard de Fluxo de Caixa — Power BI


Dashboard desenvolvido no **Power BI** com o objetivo de transformar dados financeiros em informações visuais para apoiar o **controle do fluxo de caixa, análise de despesas e tomada de decisões**.

O projeto permite acompanhar entradas e saídas, evolução do saldo, margem e distribuição das despesas por área da empresa, possibilitando uma análise financeira mais rápida e objetiva.

## 🎯 Objetivo do Projeto

O objetivo deste projeto foi desenvolver um dashboard capaz de responder perguntas importantes para a gestão financeira, como:

- Qual é o saldo atual?
- Quanto entrou e quanto saiu em determinado período?
- Qual era o saldo inicial e qual foi o saldo final?
- Como o saldo evoluiu ao longo dos meses?
- Qual categoria de despesa representa o maior impacto financeiro?
- Em qual área da empresa estão concentrados os maiores gastos?
- Qual foi a margem obtida no período analisado?

A solução foi construída para facilitar a **visualização e interpretação dos dados financeiros**, permitindo uma análise mais dinâmica através de filtros.

## 🔎 Análises Disponíveis

O usuário pode utilizar o filtro de **data** para analisar os resultados de diferentes períodos e identificar onde os recursos financeiros estão sendo mais utilizados.

As despesas são distribuídas nas seguintes áreas da empresa:

| Área | Descrição |
|---|---|
| Administrativo | Despesas relacionadas à administração da empresa |
| Comercial | Despesas relacionadas à área de vendas e comercial |
| Financeiro | Despesas relacionadas à gestão financeira |
| Marketing | Investimentos e despesas de marketing |
| Operacional | Despesas relacionadas à operação da empresa |

Essa segmentação permite identificar rapidamente **qual área concentrou os maiores gastos durante determinado período**.
